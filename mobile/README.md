# لوما — تطبيق الهاتف

تطبيق Flutter لنظامي **أندرويد و iOS**، يعمل على نفس خادم الموقع
(Firebase: المصادقة، Firestore، الإشعارات) بلا أي خادم إضافي.

الواجهة مبنية على تصميم **Paytin** المرفق: أخضر ليموني على أسود شبه كامل،
بطاقات بحواف كبيرة، وشريط تنقّل عائم على شكل حبّة دواء بزر مرفوع في الوسط.

---

## تسجيل الدخول عبر QR

لا توجد شاشة كلمة مرور. المتصفح — وهو مسجَّل الدخول أصلاً — هو من يشهد للهاتف:

1. على الموقع: **الإعدادات ← الهاتف ← إظهار رمز الاقتران**
2. في التطبيق: زر **مسح رمز الدخول**
3. يقرأ الهاتف الرمز، يستبدله بـ token، ويدخل بنفس صلاحيات المتصفح

الرمز يحمل عنوان الخادم بداخله، لذلك **لا يحتاج أحد إلى كتابة أي رابط في
الهاتف** — يعمل التطبيق نفسه مع Netlify أو Firebase Hosting أو جهاز على شبكة
المكتب.

خصائص الرمز: ‏128 بت عشوائية · صلاحية دقيقتان · يُستهلك مرة واحدة فقط
(أول جهاز يمسحه يأخذه، وأي محاولة بعده تُرفض).

## التشغيل

```bash
cd mobile
flutter pub get
flutter run
```

إعدادات Firebase موجودة ومربوطة مسبقاً:

| الملف | المحتوى |
| --- | --- |
| `android/app/google-services.json` | تطبيق أندرويد `com.lumaagency.luma` |
| `ios/Runner/GoogleService-Info.plist` | تطبيق iOS `com.lumaagency.luma` |
| `lib/core/firebase_options.dart` | نفس القيم لـ `Firebase.initializeApp` |

هذه معرّفات علنية وليست أسراراً — تماماً مثل `js/firebase-config.js` في الموقع.
الحماية الفعلية من Security Rules و custom claims.

### iOS

الإشعارات على iOS تحتاج خطوة واحدة إضافية لا يمكن إتمامها من هنا: ارفع مفتاح
APNs (‏`.p8`) في **Firebase Console ← Project Settings ← Cloud Messaging**،
وفعّل **Push Notifications** في Xcode ← Signing & Capabilities.
بدونها يعمل كل شيء عدا وصول الإشعارات على الآيفون.

## ما هو مبنيّ

- **الدخول بالـ QR** مع كاميرا وإطار مسح، ورفض أي رمز ليس من النظام
- **الرئيسية** — بطاقة المهام المفتوحة، وعدّادات اليوم / المتأخر / المكتمل
- **المهام** — «مهامي» أو «الكل»، وتصفية بالمفتوحة/اليوم/المتأخرة/المكتملة
- **تفاصيل المهمة** وتغيير الحالة مباشرة من الهاتف
- **تركيز اليوم** — الزر الأوسط: المتأخر أولاً ثم مستحقّ اليوم
- **الإشعارات** — قائمة، ونقطة على الجرس، وتعليم كمقروء يتزامن مع الموقع
- **حسابي** — الدور والصلاحيات والخادم المرتبط وتسجيل الخروج
- **الإشعارات الفورية** — تعمل والتطبيق مفتوح أو في الخلفية أو مغلق

## ما ليس مبنيّاً بعد

الموقع فيه أقسام أكثر من هذه: العملاء، المالية، المحادثات، الملفات، التقارير،
المعرفة، والمساعد الذكي. التطبيق الحالي يغطّي المهام والإشعارات — وهو ما يُفتح
الهاتف من أجله عادةً — والبقية تُبنى فوق نفس الأساس الموجود هنا.

## البنية

```
lib/
  core/      الألوان والثيم والتواريخ وإعدادات Firebase
  data/      الخادم، الجلسة، المهام، الإشعارات، وقراءة رمز الاقتران
  features/  الشاشات
  widgets/   عناصر مشتركة
```

`data/api.dart` يتكلّم **بروتوكول Firebase callable نفسه** الذي يستعمله الموقع،
لذلك يعمل مع Cloud Functions أو مع محوّل Netlify دون تغيير سطر واحد.

## الاختبارات

```bash
flutter analyze     # نظيف
flutter test        # 14 اختباراً
```

تغطّي قراءة رمز الاقتران (بما فيها رفض الروابط غير الآمنة والرموز المزيّفة)،
وقواعد «متأخرة» و«اليوم»، وقراءة مستندات Firestore الناقصة دون انهيار.
